隱私權政策

我們如何處理你的資料

本政策說明 CloudLedger 服務中資料的蒐集、使用、保存與保護方式。

1. 適用範圍

本政策適用於 Krend Studio 提供的 CloudLedger 服務與相關功能，包括 App 內的帳務記錄、 帳戶管理、同步與支援功能。

2. 蒐集的資料類型

  • 帳戶資料：Firebase Auth UID、電子郵件、顯示名稱、頭像連結。
  • 帳務資料：交易金額、類型、分類、描述、日期、回饋點數與帳本成員資訊。
  • 同步與設定：帳本清單、分類設定、週期性收支設定。
  • 使用與裝置資訊：App 版本、裝置型號、作業系統版本、基本操作紀錄。
  • 廣告與分析：廣告識別碼、互動事件與使用統計（Firebase Analytics、AdMob）。
  • 語音輸入：語音辨識文字結果（使用系統語音辨識服務）。
  • 智慧輸入：你提供的文字內容與選擇的分類清單；如你設定 API Key，會在使用時傳送至雲端函式處理。
  • 客服互動：你提交的問題與回覆內容。

3. 使用目的

  • 提供與維護服務（登入、帳本同步、跨裝置使用）。
  • 提供功能體驗（交易記錄、分類管理、語音/智慧輸入）。
  • 改善產品體驗與服務穩定性。
  • 提供廣告與服務分析，維持免費服務。
  • 符合法律義務與安全需求。

4. 第三方服務與分享

我們使用以下第三方服務以提供核心功能，並僅在必要範圍內分享資料：

  • Firebase Authentication：帳戶登入與驗證。
  • Firebase Firestore / Functions：資料同步與智慧輸入處理。
  • Firebase Analytics：使用統計與功能改善。
  • Google Sign-In：登入驗證。
  • Google AdMob：廣告投放與收益分析。
  • Android 語音辨識服務：語音輸入功能。

除依法令或政府機關要求外，我們不會出售你的個人資料。

5. 資料保存與刪除

我們會在提供服務期間保存資料。若你提出帳戶刪除申請，我們將在 7 至 30 天內完成 刪除流程。依法令或財務需求必須保留的資料，將在必要期間內限制使用並於期限後刪除。 詳細流程請參考 帳戶刪除。

部分設定（例如智慧輸入 API Key）會保存在你的裝置上，你可透過清除 App 資料移除。

6. 你的權利

  • 查詢、閱覽或取得你提供的資料。
  • 要求更正或刪除帳戶與關聯資料。
  • 撤回同意或限制特定資料用途。
  • 要求資料匯出（透過 App 內匯出功能）。

7. 資料安全

我們採取合理的技術與管理措施保護資料安全，包含存取控管與傳輸加密。 請注意，任何網路傳輸仍可能存在風險，建議你妥善保管帳戶資訊。

8. 兒童隱私

本服務並非針對未滿 13 歲的兒童設計。若你為未成年使用者，請在法定監護人同意下使用。

9. 跨境傳輸

我們的服務使用雲端平台提供，資料可能儲存於台灣或其他地區的伺服器。

10. 政策更新與聯絡

本政策如有變更，我們將於此頁公告。若你對隱私權政策有任何疑問，請參考 關於我們 的聯絡方式。
